# Specs e ADRs no repositório; acompanhamento em notas Maestri

Specs, ADRs e o CONTEXT.md vivem no repositório, versionados com o código e lidos pelos agentes de desenvolvimento. O quadro de tarefas e o status ficam em notas do canvas Maestri ("Carmine · Quadro", "Carmine · Decisões"), não em GitHub Issues, porque o projeto tem um único desenvolvedor que acompanha tudo pelo canvas. PRs citam o ID da spec e da tarefa para manter a rastreabilidade no git. Se o time crescer, migrar para Issues.
