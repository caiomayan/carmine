# MVP com servidores comunitários fixos, sem matchmaking

O MVP opera Servidores Carmine sempre ligados (Retake e Deathmatch, depois 5v5 casual), no modelo FireGames. Matchmaking com fila, ELO e servidores sob demanda fica para a Fase 2, porque exige orquestração, tempo real e moderação desde o primeiro dia (3 a 5 vezes a complexidade). O modelo de dados (Sessão de jogo, Partida, round, evento por jogador) já nasce compatível com a Fase 2.
